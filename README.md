## Описание проекта

Проект представляет собой модульное веб-приложение на базе **FastAPI**, спроектированное в соответствии с современными архитектурными практиками структурирования серверных решений.

Функционал включает:
1. **Управление пользователями (`/user`):**
   - `POST /user/signup` — регистрация нового пользователя с валидацией уникальности email;
   - `POST /user/signin` — аутентификация пользователя с проверкой пароля.
2. **Управление событиями (`/event`):**
   - `GET /event/` — получение полного списка запланированных событий;
   - `GET /event/{id}` — получение подробной информации о событии по его ID;
   - `POST /event/new` — создание нового события;
   - `DELETE /event/{id}` — удаление отдельного события;
   - `DELETE /event/` — групповое удаление всех событий.

## Установка и запуск

1. **Создание и активация виртуального окружения:**
   ```bash
   python -m venv venv
   source venv/Scripts/activate  # Для Windows (Git Bash)
   ```

2. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запуск сервера разработки:**
   ```bash
   python main.py
   # либо:
   uvicorn main:app --host 0.0.0.0 --port 8080 --reload
   ```

4. **Интерактивная документация:**
   - Swagger UI: [http://127.0.0.1:8080/docs](http://127.0.0.1:8080/docs)
   - ReDoc: [http://127.0.0.1:8080/redoc](http://127.0.0.1:8080/redoc)
