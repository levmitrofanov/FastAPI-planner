## Описание проекта

Проект представляет собой модульное веб-приложение на базе фреймворка **FastAPI**, интегрированное с реляционной базой данных **SQLite** при помощи библиотеки **SQLModel** (объединяющей возможности SQLAlchemy и Pydantic).

В работе реализовано:
1. **Интеграция реляционной СУБД SQLite:**
   - Модуль подключения `database/connection.py` с автоматической инициализацией схемы базы данных при запуске приложения (`on_startup`);
   - Внедрение зависимостей для управления сессиями транзакций (`get_session`, класс `Depends`).
2. **CRUD-операции сущности Event (`/event`):**
   - `POST /event/new` — создание нового события и сохранение в SQLite;
   - `GET /event/` — чтение полного списка событий (`select(Event)`);
   - `GET /event/{id}` — получение события по идентификатору;
   - `PUT /event/edit/{id}` — обновление атрибутов события;
   - `DELETE /event/delete/{id}` — удаление события из базы данных.
3. **Персональная тема: «Управление сетевыми узлами вычислительной сети» (`/node`):**
   - Таблица `NetworkNode` (идентификатор, хостнейм, IP-адрес, тип оборудования, рабочий статус);
   - Набор команд №1 (Create & Read): регистрация оборудования и получение топологии;
   - Набор команд №2 (Update & Delete): перевод в режим обслуживания и списание узла.
4. **Управление пользователями (`/user`):**
   - Регистрация и аутентификация учетных записей.

## Установка и запуск

1. **Активация виртуального окружения:**
   ```bash
   source venv/Scripts/activate
   ```

2. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запуск сервера:**
   ```bash
   python main.py
   ```

4. **Интерактивная документация:**
   - Swagger UI: [http://127.0.0.1:8080/docs](http://127.0.0.1:8080/docs)
